# Gestor Simple de Nombres

## Descripción
Aplicación básica en Java que demuestra el uso de ArrayList para almacenar, eliminar y recorrer una lista de nombres.

## Funcionalidades
- Crear una lista dinámica de nombres
- Añadir nombres a la lista
- Eliminar nombres específicos de la lista
- Recorrer y mostrar los nombres restantes

## Tecnologías
- Java
- ArrayList
- List (interfaz)
- For-each
